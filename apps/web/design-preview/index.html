Fix 1 — surface was invisible

#16171A sits at 1.05:1 against the background. On most laptop screens a card painted with it is indistinguishable from the page, so every card was relying entirely on its border. Compare:

Fix 2 — the red button fails contrast

White text on #FF3B30 measures 3.5:1, below the 4.5:1 minimum for body-size text. Three candidates, judge them directly:

Install the extension 3.5:1 fails AA
Install the extension 5.4:1 passes AA
Install the extension ★ Star on GitHub — 1,284 19.0:1 — recommended
Recommendation: white fill with near-black text as the primary call to action, ghost button beside it for the star. Accent red is then reserved for the asterisk mark, links, hover states and the focus ring — which keeps it rare enough to stay loud, and matches the existing rule that red never signals destruction in a product whose promise is safe undo.

Fix 3 — a visible focus ring

Red on near-black is nearly invisible as a 1px outline. A 2px ring with an offset and a dim halo is keyboard-usable:

Focused state --color-focus: 2px #FF3B30, offset 3px, halo rgba(255,59,48,.12)

Fix 4 — the logo gradient has no tokens

The orange→pink asterisk is the only gradient in the system and currently exists nowhere in the palette, which means it will get re-guessed every time someone builds a component. It should be two named tokens sampled from icon.png rather than invented. Placeholder swatch only:

Proposal 03

Bubbledot has a licence problem

The copy in F:\Fonts came from OnlineWebFonts, whose bundled licence says the collection “may be trial versions of full versions and may not allow embedding unless a commercial license is purchased”, while separately claiming CC BY 4.0. The W01 in the filename is Monotype web-package naming, which suggests the original is commercial. Shipping it on a public open-source site is a real risk.

Array, from Fontshare, occupies the same dot-matrix-adjacent instrumentation niche, ships a proper licence file, and is already in your library. Compare all three in the actual role:

01 — The problem

Your AI writes the code.
You do the typing.

Ask any chatbot to refactor twelve files and it will happily produce twelve blocks of code. Then you paste them one by one, hunt for the right line, and hope nothing drifted. Brud Code removes that step and nothing else.
