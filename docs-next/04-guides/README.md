# Guides

Task-focused recipes. Each one solves one problem and ends with something that runs.

| Guide | Use it when you want to... |
|---|---|
| [Own a kind](own-a-kind.md) | Let text commands reach your code |
| [Gate access with capabilities](gate-access-with-capabilities.md) | Give different callers different powers |
| [Use another participant's API](use-another-participants-api.md) | Call something another participant exposes |
| [Accept startup options](accept-startup-options.md) | Let the host configure your participant |
| [Emit and subscribe to events](events.md) | Announce things without coupling |
| [Intercept calls](intercept-calls.md) | Audit, modify or block calls to an exposure |
| [Schedule work for a caged participant](schedule-work-for-a-caged-participant.md) | Give a caged participant recurring work |
| [Handle errors](handle-errors.md) | Tell refusals, failures and cancellation apart |
